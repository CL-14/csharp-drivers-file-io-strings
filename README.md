# C# Drivers, File I/O, and String Formatting Demo

A modular C# console application designed to practice architectural patterns, data persistence, and text manipulation in .NET.

## Key Concepts Covered
* **Driver Pattern:** Uses dedicated driver classes (`AppDriver`, `MovieDriver`, `ProductDriver`, `FileDriver`, `StringDriver`) to organize execution logic.
* **Repository Pattern:** Simulates data layers using static repositories for `Movie` and `Product` entities.
* **File I/O:** Demonstrates writing text, lists, and formatted data objects to files within an output directory.
* **String Formatting:** Explores alignment, padding (`PadLeft`), and interpolated string formatting.

## Tech
* Language: C# (.NET Console Application)
